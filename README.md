# RackTracker 사업계획서

파워랙에 고정한 AR0234 글로벌 셔터 센서 3대로 프리웨이트 운동을 3D 좌표로 기록하고, 운동 역학으로 분석해 세트마다 피드백을 주는 장치의 사업계획서입니다.

- **사업계획서 PDF**: [business-plan.pdf](business-plan.pdf) (13쪽, 2026-09-28)
- **원본**: [business-plan.html](business-plan.html)

2026-09 창업 지원 프로그램 지원서를 사업계획서 형식으로 다시 정리했습니다. 실측값은 작성 시점의 값이고, 매출과 가격은 가정에 따른 추정입니다. 특허 출원 전이라 청구 범위와 판정 임계값은 싣지 않았습니다.

제품 코드는 비공개이며 요청 시 공유합니다. 관련 공개 저장소는 [agent-workflow-kit](https://github.com/lhk0721/agent-workflow-kit)과 [uvc-lab](https://github.com/lhk0721/uvc-lab)입니다.
