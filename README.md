# RackTracker 사업계획서

파워랙에 고정한 카메라 3대로 스쿼트를 3D로 측량하고, 반복마다 관절별 하중 분배를 계산하는 헬스장용 모션캡처 장치의 사업계획서입니다.

- **사업계획서 PDF**: [business-plan.pdf](business-plan.pdf) (16쪽, 2026-11-07)
- **원본**: [business-plan.html](business-plan.html)
- **프로젝트 사이트**: [racktracker.dev](https://racktracker.dev/) (프로젝트 보고서, 발표 자료, 시연 영상)

실측값은 작성일 기준이고, 매출과 가격은 가정에 따른 추정입니다. 청구 범위와 세부 계산 기준은 싣지 않았습니다.

제품 코드는 비공개이며 요청 시 공유합니다. 관련 공개 저장소는 [agent-workflow-kit](https://github.com/lhk0721/agent-workflow-kit)과 [uvc-lab](https://github.com/lhk0721/uvc-lab)입니다.
